# terminator-stack

A skeleton stack for frankenphp + laravel octane.

## Features
- [FrankenPHP](https://frankenphp.net/) - A high-performance PHP runtime built on top of the Terminator HTTP server.
- [Laravel Octane](https://laravel.com/docs/octane) - Supercharge your
- Redis - In-memory data structure store, used as a database, cache, and message broker.
- Docker - Containerization platform to ensure consistent environments across development and production.
- Mongodb - NoSQL database for flexible and scalable data storage.
- MariaDB - Relational database management system, a fork of MySQL.
- Envoy - Laravel's remote task runner for deployment automation.
